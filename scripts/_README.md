# 元书 Pro 脚本

## 前置条件

1. **元书 Pro**（脚本功能需 Pro）
2. **iOS 设置 → 键盘 → 元书 → 允许完全访问** —— 不开启无法联网，AI 类脚本全部失效
3. 剪贴板类脚本需在元书内开启剪贴板权限

## 使用前必改

每个 AI 脚本顶部有配置块：

```javascript
const API_KEY = 'sk-ant-xxxxxxxx'   // ← 填你自己的
const MODEL   = 'claude-opus-5'
```

⚠️ **API Key 明文存在脚本里。** 它在你设备本地，但若把配置文件夹分享给别人，
key 会一并泄露。分享前务必清空。

## 模型选择：质量 vs 延迟

键盘场景对延迟敏感，改 `MODEL` 一行即可切换：

| 模型 | 特点 |
|---|---|
| `claude-opus-5` | 默认。质量最好，但键盘里等待感明显 |
| `claude-haiku-4-5` | 快得多，纠错/大小写这类简单任务够用 |

脚本里已设 `output_config: {effort: 'low'}` —— 保持思考开启（关闭有已知副作用）
但压到最低档，这是延迟和质量之间比较合适的折中。

## 输入来源

脚本按以下顺序取文本，第一个非空的胜出：

```
$selectedText        宿主 App 中选中的文字
$pasteboardContent   剪贴板
$searchText          键盘脚本页的输入框
```

⚠️ `$selectedText` 依赖宿主 App 上报选区，**很多 App 不支持**。
不生效时用「复制 → 跑脚本」的路径。

## 返回值与替换

`output()` 返回的 String / [String] 会作为**候选词**出现，点一下上屏。

**替换原文的正确姿势**：选中要改的文字 → 跑脚本 → 点候选。
iOS 上有选区时上屏会覆盖选区，所以这一步就是替换。

返回数组时会出现多个候选并列，适合「给几种改法自己挑」的场景
（大小写转换、剪贴板工具都用了这个特性）。

## 触发方式

**A. 工具栏「脚本」按钮** —— 已在皮肤工具栏里（代号 1）。点开脚本列表选一个。
   适合脚本多、每个都不算太高频的情况。

**B. 专用按键** —— 按键动作写 `action: { runScript: '脚本名' }`，一点直达。
   适合最高频的一两个。

**C. 长按网格** —— 一个键长按弹出脚本网格，每格一个 `runScript`。
   一个键位承载多个脚本，是 A 和 B 的折中。
